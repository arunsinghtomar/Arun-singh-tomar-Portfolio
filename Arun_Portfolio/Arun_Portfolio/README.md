# Arun Singh Tomar — Developer Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript to introduce my skills, projects, education, and learning experience.

## Features
- Responsive desktop and mobile layout
- About, skills, projects, experience, and contact sections
- Mobile navigation menu
- GitHub and LinkedIn profile links
- No build tools or package installation required

## Project structure
```text
Arun_Portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run locally
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Update before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
- Confirm your internship and education details are accurate.
- Update the FocusFlow and CleanX links if your repository names differ or you have not published those repositories yet.
